creature_pkmod_compatibility

This file defines the creatures added by pks mod, so that they dont throw errors when not using that mod in conjunction with this mod.
It is intended to have no effect when not using both mods.
If you use both, this one should be loaded after pks lite mod.

-Since all giant variations of cavern animals in vanilla are 'unique species' and have no base creature, giant versions of exclusively underground creatures I add will get knocked down 3 tiers instead of the normal 2 and have the savage tag removed-
-The rules in the cave are somewhat different than the surface-
